# 每日营业统计

入口：商家端「数据报表 → 营业额统计」。

1. 选今天、昨天、近7天、本月，或最多366天的日期范围。
2. 上方展示净营业额、收款订单数和日均营业额；趋势可按日、周、月查看。
3. 在「每日汇总」点「查看当天」（手机直接点日期卡片），查看当天订单、菜品、收款流水和退菜免单。
4. 点「看账单」查看每道菜的数量、单价、小计、口味、加菜时间及该单操作记录。订单支持搜索桌号或订单号。
5. 「导出完整明细」导出所选范围；「导出当天明细」只导出所选日期。

## 金额与日期口径

- 以北京时间自然日统计。当前现金、微信/支付宝收款码在确认到账时创建支付流水，按该时间归集；跨天开单在收款日入账。
- 收款采用入账金额，现金已扣除找零；待支付、失败、逻辑删除的收款或订单不纳入实收。
- 净营业额 = 当日收款 − 当日整单退款。退款按退款审计时间归集，原收款仍留在原收款日，退款日可以出现负营业额。
- 微信、支付宝、现金和其他净额分别扣除对应方式退款，合计等于净营业额。
- 收款订单数是当日有成功收款流水的去重订单数。同一账单加菜不新增订单；跨天分次收款在各收款日分别计数。零金额免单没有收款流水，不计入收款订单数。
- 日均营业额除以所选自然日天数，包括零营业日期。周使用 ISO 周及 ISO 周年；周/月只汇总筛选范围内日期。
- 结账前退菜、免单、折扣已影响账单应收，不再从收款重复扣除；它们与收款后的整单退款分开列示。
- 当天明细包含当天开单、收款或发生调整的订单。账单应收、当前待收、状态及菜品是查询时状态，不是历史余额快照；当前待收只包含尚待结账的应收差额。
- 菜品明细显示关联订单当前保留的菜品，跨天收款可能关联前一天所点菜品；退掉或换掉的菜见操作记录。菜品小计尚未分摊整单折扣，不等同于当日实收。
- 历史审计日志未记录金额时显示「未记录」并在 Excel 留空，不根据现价推算。

## Excel

工作簿包含六张表：每日汇总（含合计）、订单明细、菜品明细、收款退款流水、退菜免单记录、统计说明。表头冻结，金额显示两位小数，订单/流水号以文本保存。跨日期关联同一订单时，订单明细按统计日期分别列出当日收退款，菜品明细只导出该订单一次。

此功能仅查询现有业务表，不新增或修改订单、流水、库存和桌台状态，不需要数据库迁移。当前真实在线支付未启用；未来接入时需以支付平台成功时间完善对应日期口径。
