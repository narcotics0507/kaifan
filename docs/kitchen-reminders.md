# 厨房电子单和语音

不依赖打印机。新单、每批加菜按持久化厨房编号提醒；WebSocket及8秒轮询使用同一票据ID去重，退菜、补打不会变成新单提醒。打开页面时现有单据作为基线，不自动重读；首次读取小票失败后重试，也会识别基线后新增的菜品批次。

营业时保持厨房页在前台、屏幕亮着，设备音量打开，先点「试播」。切后台时暂停语音，尚未播完的本页提醒保留；回到前台或网络恢复时立即读取账单，尝试补播。浏览器拒绝声音时提示重新开启，关闭声音会清除待播语音。页面刷新或关闭后重新建立历史基线，必须目视核对已有电子单据。网页不保证手机锁屏或后台持续运行。

本地验收使用独立桌台，不向生产提交假订单。浏览器网络隔离、首个小票请求失败、切后台、接口返回重复票据、轮询和语音回调可以测试；真实iPhone/安卓手机/安卓平板及不同浏览器的实际可听性仍须现场试播。设备验收建议覆盖前台新单与加菜、短暂断网再恢复、切后台回前台、静音再开启以及刷新不重读旧单。
