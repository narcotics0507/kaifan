# Kaifan

A single-store, dine-in QR ordering system with a customer H5 app, mobile-friendly merchant administration, combined table billing, manually confirmed payments, kitchen queue numbers and dish photo upload.

This is a derivative of [YHlorra/diancan-system](https://github.com/YHlorra/diancan-system), based on commit `3ab6ca9c7a024e38516a2a343d99b6ab3e3060bd`. The merchant UI retains the Soybean Admin MIT notice. See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) and [LICENSE](LICENSE).

See the [Chinese README](README.md) for setup and current limitations, and [deployment instructions](deploy/README.md) for GitHub Actions. Real online payment and physical cloud printing are not currently enabled. Production credentials and business backups are not included.
